# C8 proposal: H1 producers + H2 pass capture (ABI 0.1 → 0.2, append-only)

Status: PROPOSED by Claude 2026-10-24 for Astra's ack (A2-R02). Implementation proceeds on
`claude/c8-h2` in parallel; layouts below change only if Astra's ack asks.

## 0. Finding that changes C8's scope
`host_observe` is **transport only**. No code in the repo emits any H1 event (resources, descriptors,
lists, queues): the producers were never rebuilt after the recovery. H2 needs those identities, so
C8 delivers **both**: H1 producers (frozen 0.1 vocabulary, no ABI change) and the H2 additions.

## 1. Producers (no ABI change)
- **Identity:** COM pointer → `na_object_id` (monotonic). Retirement uses a private-data sentinel
  (`ID3D12Object::SetPrivateDataInterface`): its final `Release` runs when the object is destroyed →
  `NA_EV_OBJECT_RETIRED`, map entry dropped. No `Release` hooks.
- **Device** (vtable hooks; shared by every device of that implementation): CreateCommittedResource
  (+1/2/3), CreatePlacedResource (+1/2), CreateReservedResource (+1/2), CreateHeap(1),
  CreateDescriptorHeap, Create{ShaderResource,UnorderedAccess,RenderTarget,DepthStencil,ConstantBuffer}View,
  CopyDescriptors(Simple), CreateCommandList(1), CreateCommandQueue(1), CreateFence,
  CreateGraphicsPipelineState, CreateComputePipelineState, CreatePipelineState, CreateRootSignature.
- **Descriptor addressing:** a heap table (CPU/GPU start, increment, count) resolves a handle to
  `(heap, slot)` and its current `slot_version`; unresolvable handles stay `NA_UNKNOWN_*`.
- **GPU VA → resource:** interval table from buffer creation + `GetGPUVirtualAddress` (shared with C9).
  Overlapping intervals (aliased placed resources) resolve to *ambiguous*, never a guess.
- **Command lists:** slots registered with the existing variant registry (A48/A49) so per-list driver
  tables are covered; coverage gaps mark ops `NA_EVF_METHOD_UNOBSERVED` / the recording gapped.
- **Queues:** ExecuteCommandLists (already hooked by the host) → `NA_EV_QUEUE_EXECUTE`; Signal/Wait.

## 2. ABI 0.2 additions (MINOR, append-only)
`NA_OBSERVE_ABI_MINOR 2`; new kinds are skipped by 0.1 consumers via `size_bytes`.

| Kind | Group | Content |
|---|---|---|
| `NA_EV_ROOT_SIGNATURE_CREATED = 24` | PIPELINE | id, device, blob FNV-1a-64 + size, flags, params via offset/stride: type, visibility, (constants: register/space/count) or (table: range count, first range type/register/space/count) or (root view: register/space) |
| `NA_EV_PIPELINE_CREATED = 25` | PIPELINE | id, device, root signature id (0 = embedded/unknown), kind (graphics/compute/stream), per-stage (VS/PS/DS/HS/GS/CS/AS/MS) bytecode FNV-1a-64 + size, RT count, RTV formats[8], DSV format, sample count, depth enable/write/func, blend-enable mask |
| `NA_EV_LIST_OP = 26` | PASS / RESOURCE_USE / CPU_CONSTANTS by op | list id, recording_generation, op_index (per recording), op code, fixed op fields + variable payload at offset/size |

`LIST_OP` op codes: SET_PIPELINE, SET_ROOT_SIGNATURE (gfx/compute), SET_DESCRIPTOR_HEAPS,
SET_ROOT_TABLE (param, heap, slot, slot_version), SET_ROOT_CONSTANTS (param, dest offset, count, **bytes
by value**), SET_ROOT_VIEW (CBV/SRV/UAV: resource + offset, or unknown), OM_SET_RENDER_TARGETS (up to 8
RTV + DSV refs: heap, slot, version, resource, format, subresource), CLEAR_RTV, CLEAR_DSV (resource +
values), DRAW, DRAW_INDEXED, DISPATCH, EXECUTE_INDIRECT (flagged: effects unobserved), COPY_RESOURCE,
COPY_BUFFER_REGION, COPY_TEXTURE_REGION, RESOLVE, RESOURCE_BARRIER (type, resource, subresource,
before/after; enhanced barriers flagged unobserved), RS_VIEWPORT (first viewport), RS_SCISSOR.

Flags reuse H1: `METHOD_UNOBSERVED` for gaps, `TRUNCATED` for byte budgets. Bundles and
ExecuteIndirect stay flagged (A2-R02). Bindless indexing is visible only as root constants + heap
writes; GPU-written descriptors/data are not observable and are stated as such.

## 3. Validation
WARP tests (run in CI, no GPU): a fixture-style frame with known passes (clear → depth pass →
color pass → copy), checking identities, op order, bindings, root constants by value, barriers, PSO
hashes, retirement, and a deliberately unobserved path producing the flag rather than invented data.
Then Cort's RTX run.
