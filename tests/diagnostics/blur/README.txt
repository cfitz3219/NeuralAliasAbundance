Diagnostic scripts require Python, NumPy, Pillow and OpenCV. Run from the repository root against the local/blur-isolation captures. No game data is included. matrix-analysis.py takes a capture folder argument; register.py takes one or more folders. smaa-analysis.py uses the session's two fixed capture folders and writes motion-corrected planes for the manual blur_replay composed-motion mode. No game files or production rendering code are changed by these scripts.
